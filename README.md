# Community tracker free Google test

New isolated public static frontend for a synthetic consumer-account Google Apps Script/Sheets experiment.

Only frontend files and an intentionally public garden-event sample are published. Google identity and private backend setup are pending; private requests are disabled. No Sheet contents, credentials, account identifiers, Apps Script backend source or production configuration are in this repository.

Once approved, public config receives only a web client ID and new deployment URL. Server-side identity validation and record authorization remain mandatory. Existing SMP sites are unrelated and untouched.
